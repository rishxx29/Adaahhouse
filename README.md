# Adaahhouse — Grace in Every Thread

Luxury Indian ethnic wear and curated kurti collections celebrating everyday grace.

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/5e522e10-f8d2-4b45-a1bf-d77a4fc7c497

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
